Round 2

SEND concepts of what to change

In this round we tested out various ways to improve the journey:

  • Helping users select their provider - a short quiz, a table of key facts and a table of short blurbs about each provider
  • Auto-selecting course or provider based on journey
  • Choose a second provider or state no preference for provider, to help with getting a funded place
  • Providing a magic link to the provider application form after submitting registration
  • Autofilling data in the provider application form for questions DfE has already asked the user
