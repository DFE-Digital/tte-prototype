SEND pages and choose a provider

In this round we tested the idea of having something to help users select their provider. We had 3 different versions of this - a short quiz, a table of key facts and a table of short blurbs about each provider.

This was part of a wider research round, which also included various ideas for how to improve the registration journey.

Pages within the collection:

  1. Professional development
  2. TTE guidance
  3. Leading SEND and inclusion (leaders) course
  4. Supporting SEND and inclusion (teachers) course
  5. Compare providers using table
  6. Compare providers using blurbs
  7. Compare providers using short form
